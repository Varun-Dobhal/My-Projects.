# Travel Checklist 🧳✈️

A mini React project that helps in creating and managing a **travel packing list**.  
This project was built to practice the **useState Hook** by handling dynamic lists and state updates.

---

## ✨ Features
- ➕ Add new items to the travel checklist  
- ❌ Remove items from the list  
- ✅ Mark items as packed/unpacked  
- Clean, minimal UI with **plain CSS**  
- Demonstrates state updates for lists in React

---

## 🛠️ Tech Stack
- **React** (Functional Components + Hooks)  
- **JavaScript (ES6+)**  
- **Plain CSS** for styling
