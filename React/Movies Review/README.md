# Movies Review App 🎬⭐

A mini React project where users can search for movies and add reviews.  
This project was built to practice **useState Hook** along with **data fetching in React**.  
It simulates a real-world scenario of handling APIs, state updates, and rendering dynamic data.

---

## ✨ Features

- 🔍 Search movies by title
- 🎥 Fetch movie details dynamically (from API / mock data)
- 📝 Add and manage reviews for movies
- ⭐ Display user ratings/reviews
- Clean and responsive UI with **plain CSS**

---

## 🛠️ Tech Stack

- **React** (Functional Components + Hooks)
- **JavaScript (ES6+)**
- **Fetch API / Async Data Handling**
- **Plain CSS** for styling
