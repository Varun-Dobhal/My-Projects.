# Next Step 🚀

A mini React project built while learning **useState Hook**.  
This project demonstrates the core concept of state management in React through simple yet powerful examples.

---

## ✨ Features
- ➕ Increment counter  
- ➖ Decrement counter  
- 🔄 Toggle functionality (show/hide text or element)  
- Clean and minimal UI with **plain CSS**

---

## 🛠️ Tech Stack
- **React** (Functional Components + Hooks)  
- **JavaScript (ES6+)**  
- **Plain CSS** for styling
