# Pizza Menu App 🍕🔥

A modern React app to browse and explore delicious pizzas fetched from a free recipe API.  
This project was built with **Vite** for fast development, **Tailwind CSS** for styling, and **React Query** for advanced data fetching and caching.

---

## ✨ Features
- 🍕 Browse pizzas from a free recipe API  
- 🔄 Fetch and cache data using **React Query**  
- ⚡ Super-fast development with **Vite**  
- 🎨 Fully responsive UI with **Tailwind CSS**  
- 🛠️ Demonstrates multiple data fetching & state management concepts  

---

## 🛠️ Tech Stack
- **React + Vite**  
- **JavaScript (ES6+)**  
- **React Query** (for data fetching, caching, and background updates)  
- **Tailwind CSS** (utility-first styling)  
- **Free Recipe API** (for pizza data)
