# Quiz App 📝🎯

A mini React project designed to test knowledge through a simple quiz.  
This project was built to practice **breaking down UI into reusable components** and learning **data fetching in React**.

---

## ✨ Features
- 🧩 Multiple-choice questions  
- 🔄 Fetch quiz data dynamically (API or JSON file)  
- ✅ Show selected answers and track score  
- 🏆 Display final result at the end  
- 🎨 Clean and minimal UI with **plain CSS**  
- Demonstrates component-based architecture in React

---

## 🛠️ Tech Stack
- **React** (Functional Components + Hooks)  
- **JavaScript (ES6+)**  
- **Fetch API / Async Data Handling**  
- **Plain CSS** for styling
